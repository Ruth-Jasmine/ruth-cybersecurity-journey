# Consulting Frameworks

ISO 27001, NIST CSF, and other methodologies used in cybersecurity consulting.

## What lives here

- Framework breakdowns (NIST CSF, ISO 27001, CIS Controls)
- Notes on how each framework gets used in real consulting engagements
- Risk assessment methodologies and templates
- Sample deliverable formats (gap analyses, control assessments, executive summaries)

## Suggested learning order

1. **NIST CSF 2.0** — most accessible starting point. Six functions: Govern, Identify, Protect, Detect, Respond, Recover. Free, widely adopted, translates across industries.
2. **CIS Controls v8** — concrete and prescriptive. Useful when clients want "what do I actually do?" answers.
3. **ISO 27001:2022** — formal, certification-based. 93 controls organized into 4 themes: Organizational, People, Physical, Technological.
4. **NIST 800-53** — heavyweight, US federal context. Learn later, only if relevant to a target sector.

## Why this matters for consulting

Frameworks are the shared vocabulary consultants use with clients. Knowing one framework deeply is more valuable than knowing five superficially. NIST CSF is the highest-leverage starting point: free, well-documented, and used by organizations of every size.
