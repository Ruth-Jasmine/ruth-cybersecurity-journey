# Cybersecurity Fundamentals

Notes and labs covering Security+ topics and foundational cybersecurity concepts.

## What lives here

- Topic notes organized by Security+ SY0-701 domain
- Concept summaries (CIA triad, defense in depth, zero trust, etc.)
- Hands-on notes from foundational tools (Wireshark, Nmap, basic scripting)

## Security+ SY0-701 domains

*Current as of May 2025 — verify the exam code is still SY0-701 at comptia.org before scheduling.*

1. **General Security Concepts** (12%)
2. **Threats, Vulnerabilities, and Mitigations** (22%)
3. **Security Architecture** (18%)
4. **Security Operations** (28%)
5. **Security Program Management and Oversight** (20%)

## Suggested study order for weeks 1–8

- Weeks 1–2: General Security Concepts + foundational vocabulary
- Weeks 3–4: Threats, vulnerabilities, and mitigations
- Weeks 5–6: Security Architecture
- Weeks 7–8: Security Operations + Program Management

Reserve weeks 9–12 for full-length practice exams, weak-area review, and the exam itself.
