# Reading Summaries

Summaries and notes from papers, articles, books, and other reading.

## What lives here

- One markdown file per substantive paper, book chapter, or report
- Each summary follows `summary-template.md`
- Quick-hit notes on shorter articles can be grouped into a monthly digest file

## Why summarize

A summary you write is worth ten papers you read passively. Writing forces synthesis. Public writeups also signal to future employers that you process information seriously.

## Categories to fill out over time

- **Foundational cybersecurity** — Verizon DBIR, Mandiant M-Trends, ENISA Threat Landscape
- **Application security** — OWASP guides, classic web-app papers
- **AI security** — adversarial ML, RLHF safety, LLM-specific threats
- **Consulting and communication** — writing for executives, technical-to-business translation

## Starter reading list

Pick 1–2 to begin:

- *The Cybersecurity Career Master Plan* (Helen E. Patton et al.) — the most directly relevant book for this transition
- *Cybersecurity Career Guide* (Alyssa Miller) — practical, current
- Verizon DBIR (latest year) — annual breach data, free
- NIST CSF 2.0 reference document — short, foundational
- For AI security: OWASP Top 10 for LLM Applications (latest version) — short, free, the field's current standard
