# Labs and Projects

Hands-on lab writeups and personal cybersecurity projects.

## What lives here

- TryHackMe / HackTheBox writeups (process-focused, not flag-dumps)
- Home lab build documentation
- Tool walkthroughs (Wireshark, Burp Suite, Nmap, Metasploit basics)
- Capstone-style projects that demonstrate consulting-relevant skills

## Suggested starting platforms

- **TryHackMe** — most beginner-friendly; structured learning paths
- **HackTheBox Academy** — paid, more rigorous, broader coverage
- **OverTheWire (Bandit)** — free Linux fundamentals via a wargame
- **LetsDefend** or **Blue Team Labs Online** — defensive / SOC-focused (closer to consulting reality than red-team labs)

## Project ideas that connect to consulting

- A mock NIST CSF gap assessment of a fictional small business
- A Wireshark analysis of a known malware capture with an executive-level summary
- A prompt-injection demonstration against a sandboxed LLM, with written mitigation recommendations
- An ISO 27001 control mapping for a hypothetical cloud-first startup

Each of these doubles as a portfolio piece *and* practice for the kind of deliverable a junior consultant produces.

## A note on integrity

Public writeups should never include flags or full solutions for active challenges. Most platforms allow process-level writeups (your approach, what you learned) but explicitly prohibit publishing answers. Read each platform's policy before posting.
